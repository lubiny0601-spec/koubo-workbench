# 口播工作台

一个用于生成口播话术、拆解 AI 概念的本地网页工作台。把脑子里模糊的想法，变成嘴里说得清楚的话。

## 功能

- **话术生成**：输入关键词或粘贴素材，选择 15 秒 / 60 秒 / 3-5 分钟三档时长，生成带分段结构与表演指导（停顿、重音、语气、情绪）的口播脚本。
- **概念解释器**：输入一个 AI 概念，拆成"是什么 / 为什么要用 / 背后逻辑"三层，并可一键转为口播脚本。
- **AI 设置**：填入任意 OpenAI 兼容的 API 密钥后，即可解释任意概念、生成任意主题的话术。

## 使用

直接用浏览器打开 `index.html` 即可运行，无需安装依赖。

未配置 API 密钥时，内置 Agent、RAG、Embedding 等演示数据；配置密钥后调用真实模型。

在左侧栏底部点击"AI 设置"，填入：

- API 地址（默认 `https://api.deepseek.com/v1/chat/completions`）
- API 密钥
- 模型名称（默认 `deepseek-chat`）

密钥只保存在浏览器本地（`localStorage`）。
